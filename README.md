# City-Library-After-School-Program
## Overview

This project focuses on preparing and consolidating library data for an End-of-Summer Reading Report.

A city library runs an After-School Program that maintains information about student members and the books they have borrowed. During the annual Reading Kickoff event, students can also borrow books without using their membership cards. Since these transactions are recorded separately on the library's website, they are not included in the program's regular borrowing records.

As the library's data assistant, the goal of this project is to bring these separate data sources together, ensure the information is accurate and consistent, and prepare a clean, complete dataset that can be used reliably for the final reading report.

## Project Goal

The project will focus on:

* Collecting data from the available sources.
* Cleaning and standardizing the data.
* Identifying and handling missing or inconsistent information.
* Combining the relevant datasets into a unified structure.
* Producing a reliable dataset ready for further analysis and reporting.

The final deliverable will provide the library with a clean and well-structured data foundation for its End-of-Summer Reading Report.
